# 预约规则

## 什么时候可以预约

当某书目的**可借复本数为 0**（全部借出）时，读者可以预约。有可借复本时请直接借阅，系统不接受预约。

## 预约队列

- 预约按 **FIFO（先到先得）** 顺序排队，队列号越小越靠前。
- 队列号在预约成功后由系统分配，读者可以随时查询自己的排队位置。
- 同一读者对同一书目只能有 1 条有效预约，重复预约会被拒绝。

## 到馆保留期

- 预约图书归还入库后，系统按队列顺序通知下一位读者，该书进入"到馆保留"状态。
- **到馆保留期为 3 天**（含通知当日）。
- 3 天内未到馆借出：预约自动过期出队，同时：
  1. 该读者信用分 **−3 分**；
  2. 系统自动通知队列中的下一位读者。

## 预约的取消

- 读者可在"我的图书馆 → 我的预约"中自行取消，也可请馆员或智能助手协助取消。
- 取消预约不影响信用分。
- 已进入"到馆保留"状态的预约取消后，名额立即顺延给下一位读者。

## 预约状态说明

| 状态 | 含义 |
|---|---|
| WAITING | 排队等待中，前排队列还有其他人 |
| READY | 图书已到馆，正在为您保留（3 天内须到馆借出） |
| FULFILLED | 已成功借出，预约完成 |
| EXPIRED | 到馆保留超期未取，自动失效 |
| CANCELLED | 读者主动取消 |

## 常见问题

### 预约后多久能拿到书

取决于前面有多少人预约以及当前借出图书何时归还。系统会在图书归还入库后立即通知您，请留意短信与小程序消息。

### 可以预约多少本

预约数量不占用可借册数额度，但同一书目只能预约 1 次；建议同时保留的"到馆保留"预约不超过 3 本，避免集中到馆后无法在 3 天内全部取走。
