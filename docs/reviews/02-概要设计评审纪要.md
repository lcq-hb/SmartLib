### 2.3 契约一致性核对（概设 vs 蓝图）

| 核对项 | 蓝图取值 | 概设取值 | 一致性 |
|---|---|---|---|
| 统一响应体 | `{"code":0,"msg":"ok","data":{...},"traceId":"..."}` | 同 | 一致 |
| 分页结构 | `{"list":[],"total":0,"page":1,"size":20}` | 同 | 一致 |
| 内部签名头 | `X-Internal-Sign`(HMAC) + `X-Trace-Id` | 同 | 一致 |
| 借书接口幂等 | `Idempotency-Key` 必填 | 同 | 一致 |
| 库存扣减唯一入口 | `book_stock` + 必须带 `available_copies >= #{n}` | 同 | 一致 |
| 兜底幂等表 | `idempotent_record`（uk(`idem_key`)） | 同 | 一致 |
| 服务实例数 | backend ×2 + nginx | 同 | 一致 |
| 降级路径 | 查库存→"预计可借"；推荐→热门榜；检索→DB 直查 | 同 | 一致 |
