# 效果截图的存放与复现方式

README 顶部引用的 4 张截图放在这个目录。**这些截图必须来自真实运行**，
不是设计稿、也不是拼的图 —— 本项目所有对外展示的数字都要求可复现，截图同理。

## 怎么拍

1. 按 README §4.1/§4.2 起后端和 Agent（`http://127.0.0.1:8080` + `:8000`）
2. 浏览器打开 <http://127.0.0.1:8080/demo.html>
3. 把浏览器窗口调到 **宽度 1200–1600 px**（半屏即可），按下面的操作点按钮，再截图
4. 截图用 `Win + Shift + S` 取区域，**不要截进任务栏、其他标签页、鼠标悬停提示**
5. 存成 PNG，单张控制在 **500 KB 以内**

## 四张图分别拍什么

| 文件 | 拍哪个卡片 | 操作步骤 | 画面里必须能看到 |
|---|---|---|---|
| `01-search.png` | ① 书目检索 | 点「拼音首字母 jsjwl」 | 关键词输入框、`query=jsjwl` 的 meta 行（HTTP 200 + 耗时 + total）、结果表首条是《计算机网络：自顶向下方法》 |
| `02-idempotency.png` | ② 借书幂等 | 点「自动选一本可借的」→「第 1 次借书」→「用同一个 Key 再借一次」 | 幂等键、两次的 meta 行、**绿底的结论行**（同一个 Key 只扣了一次库存 ✔）、下面 JSON 里两次 `borrowId` 相同且 `idempotentReplay: true` |
| `03-reconcile.png` | ③ 对账与策略 | 点「查询对账」 | `consistent: true`、`violationCount: 0`、绿底结论行，以及右边的策略下拉框（能看出六种策略） |
| `04-agent-chat.png` | ⑤ Agent 对话 | 点「查真实库存」 | 回答里含真实馆藏数字与索书位置、下面的 `tool_calls` 表（`get_stock` + 参数 + OK）、再下面的运行时标记（意图置信度 / 有工具证据） |

**为什么是这四张**：它们分别对应这个项目最值钱的四个卖点 ——
检索（自研倒排 + 拼音）、幂等（重复提交只生效一次）、对账（零超卖的自动化证据）、
Agent（回答来自工具返回的真实数据）。面试官扫一眼 README 就能同时看到这四件事。
